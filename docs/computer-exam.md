# 练习与机考模拟

以 IELTS 官网当前链接的 Inspera 体验示例为界面参考：<https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test>。官网体验示例不计时；本项目模考按考试规则计时。听力与学术阅读分别模拟，考试操作用英文，入口与复盘用中文。

## 流程与操作

题库／模考入口 → 考前说明与材料预检 → 听力试音 → 正式开始 → 答题与标记 → 检查并确认交卷 → 原位判分与错因复盘。

准备阶段不创建答题记录、不计时。听力模考要求播放示例并确认听到声音，四段录音全部读取到有效时长后才开放开考。示例音频与试卷录音独立，不提前播放试卷内容。练习可跳过听力试听确认。

阅读显示当前 Passage 与对应题目，左右栏独立滚动并可调整宽度。听力翻题不会改变正在播放的录音。分段、答案、标记、笔记与高亮可保留；分段／标记／标注为当前浏览器按 attempt 保存，答案和逐题用时继续使用草稿 API。学习画像中的「查看复盘」可重新打开已提交试卷，返回时回到学习画像。手动交卷显示已答、未答和标记题概览，点击题号可返回对应分段；确认交卷后统一判分。

听力提交后的反馈页保留原位作答区与题号导航。逐题证据和解析面板提供「在原文中定位」：打开原文并滚动到对应答案句，以题号标签高亮；同一答案句被多题共用时合并显示题号。原文工具栏可切换答案句高亮，并用上一处／下一处按题号顺序浏览。答案句先按忽略大小写、标点和换行的 token 匹配，再对措辞略有差异的句子做近似匹配；过短或无法唯一匹配的短句不会误标，改为提示手动查找。

练习使用可重置的已用时间、可暂停回放的播放器与 AI 导师。模考阅读共 60 分钟；模考听力按四段真实媒体时长连续单次播放，不开放暂停、跳转、倍速与手动切换录音。录音内已有的读题／检查停顿不另外叠加；四段结束后统一检查 120 秒。

## 组卷与接口

- `POST /api/mock/prepare { section }`：按 Part／Passage 随机抽取完整活动并保存快照，返回去掉答案与原文的 `activity`，包含 `mockId` 和 `examParts`。听力每段 10 题；阅读选取三个题量之和为 40 的 Passage。不拆题组、不改变题目 ID；展示题号统一为 1–40。
- 听力选材要求音频、逐字文本与完整题量，排除含“10 分钟誊写”指令的材料。材料不足时停止组卷并说明缺少的分段。组合模拟卷不宣称为原版成套试卷。
- `POST /api/mock/start { section, mockId, audioDurationsSeconds? }`：使用已保存快照正式创建 attempt。听力提交预检读取的四段时长；服务端校验后固定 `examTiming`，返回 `deadlineAt`。阅读忽略媒体时长并固定为 3600 秒。
- 试卷以 `fullmock:<section>:<uuid>` 为 ID，保存在 SQLite／Neon 的 `mock_papers(id, activity_json, created_at)`。快照包含服务端判分数据；公开 DTO 仅下发必要题目、分段映射和音频地址。
- 两种仓储的 drafts／attempts 自动新增 `exam_timing_json`。草稿保存接口不接收时长改写；截止时间始终由服务端开始时间加固定时长生成。恢复与历史结果接口从同一试卷快照读取材料。

媒体时长来自浏览器元数据，此系统为自学模拟，不是防篡改考试客户端。客户端以固定截止时间锁定作答；没有增加后台定时服务或远程监考。

## 恢复、交卷与学习记录

后台运行、刷新和音频故障不延长模考。JSON 学习接口通过 `X-Server-Time` 校准浏览器时钟，倒计时与听力时间线共用该时间基准；以浏览器单调时钟推进，避免设备时钟偏差导致多出考试时间。恢复音频按开始时间和录音时长计算当前 Part 与偏移，不从头重播；如浏览器限制自动播放，显示 Resume audio，由用户触发恢复，时钟仍继续。音频失败记录 interruption 并开放重试；恢复时回到当前考试时间点。

到时关闭交卷确认窗口、锁定答题区并自动提交；网络失败后保持答案锁定，用户可重试同一份答案。服务端提交幂等，重复提交不重复计分和安排复习。明确退出放弃 attempt；意外中断保留草稿。判分结果中的 `materialId` 与错题队列关联原活动，保证组合模考错题可单独复习，且不会重复计为新的独立题目。

组卷只处理已加载的活动元数据和 40 道选中题目，不解码、复制或加载整库音频。现有约 305 份活动下预计一秒内完成；额外内存为单卷 JSON，通常低于 1 MB。预检只读取选中录音元数据，播放预取下一段；媒体仍通过流式接口读取。无新增运行依赖。

验证使用 `npm test`、`npm run typecheck`、`npm run build`，并在独立临时数据库中做 1280×720、1440×900 的浏览器流程与截图检查。
