# 本周体验优化任务清单 · 2026-10-23

## 本周目标

解决页面操作反馈慢、听力提交后难以定位原文证据、个性化功能与 API 链路不稳定，以及 AI 导师不可用的问题。任务按可独立领取的工作拆分；领取人和进度由开发者填写。

## 任务看板

| ID | 优先级 | 任务 | 领取人 | 状态 |
|---|---|---|---|---|
| UX-01 | P0 | 定位并修复 AI Tutor 不可用 | 未领取 | 待开始 |
| PERF-01 | P0 | 排查并优化核心交互响应速度 | 未领取 | 待开始 |
| API-01 | P1 | 梳理并优化个性化功能的 API 调用链路 | 未领取 | 待开始 |
| LISTEN-01 | P1 | 听力提交后支持原文答案句高亮与定位 | 未领取 | 待开始 |

领取方式：将“领取人”改为姓名，并在状态栏更新为“进行中”；完成后补充 PR/提交链接及验收结果。

## UX-01 · 修复 AI Tutor 不可用

**优先级：P0**　**建议负责人：前后端联调**

- [ ] 在本机和正式环境各复现一次，记录页面入口、操作步骤、请求 URL/状态码、响应错误和服务端日志关联信息；不得记录密钥或用户敏感内容。
- [ ] 覆盖 Tutor 打开、发送消息、流式/非流式响应（按当前实现）、会话恢复，以及练习提交后的 Tutor 入口；确认考试进行中等既有限制仍然正确。
- [ ] 沿浏览器 → API 路由 → AI 服务逐段定位故障，检查环境变量、模型可用性、请求格式、超时与响应解析；区分配置错误、上游错误和前端错误。
- [ ] 修复根因；界面在加载、成功、无配置、上游失败和超时时给出可理解状态，并允许失败后重试。
- [ ] 验收：真实请求返回导师回复；对话按预期保存并可恢复；无可用模型/网络失败时有明确错误而非卡死；考试限制保持有效。

**完成证据：** 本机/正式环境复现与修复结果、真实调用验收结果、PR/提交链接。

## PERF-01 · 核心交互响应速度

**优先级：P0**　**建议负责人：前端 + API**

- [ ] 选取常用路径建立基线：导航/页面打开、开始练习、切换题目、保存答案、提交、打开解析/Tutor、个性化计划加载与保存。
- [ ] 记录每步的用户感知耗时、浏览器请求耗时及主要慢请求；检查重复请求、串行请求、重复渲染和大响应体。
- [ ] 优先修复用户点击后无反馈、同一操作重复触发、可并行请求被串行等待等明确瓶颈；耗时操作显示进行中状态并防止重复提交。
- [ ] 对首屏/交互关键路径做针对性优化，避免改变判分、草稿恢复及考试计时语义。
- [ ] 验收：复测相同路径并记录优化前后数据；交互状态清晰，答案保存/提交无丢失或重复副作用。

**完成证据：** 基线及复测数据、主要瓶颈和修复说明、PR/提交链接。

## API-01 · 个性化功能与 API 调用链路

**优先级：P1**　**建议负责人：全栈**

- [ ] 盘点个性化目标保存、当日计划 bootstrap/生成、预览、确认、重试等调用，绘出调用顺序并标明重复或不必要的请求。
- [ ] 检查服务端校验、失败响应、超时/重试行为和 SQLite/Neon 一致性；确保 AI 规划失败或校验失败时保留现有计划并可重试。
- [ ] 去除可确认的重复调用和重复计算；保持既有每日计划固定、题目范围校验及数据隐私约束。
- [ ] 补齐加载、成功、失败、重试的界面反馈；保存目标时避免重复提交，失败保留用户输入。
- [ ] 验收：目标保存只触发必要请求；计划加载/生成/确认结果与服务端状态一致；AI/API 失败不会覆盖已有计划，用户可理解并重试。

**完成证据：** 调用链路图或简要说明、请求次数/失败路径对比、PR/提交链接。

## LISTEN-01 · 听力原文答案句高亮

**优先级：P1**　**建议负责人：前端**

- [ ] 在听力提交后的反馈页，为每题提供“定位原文”入口，并定位到包含答案证据的原文句子。
- [ ] 高亮应能处理答案证据跨句或多个片段的情况；当前题目高亮清晰，切换题目后同步更新。
- [ ] 若原文/证据尚未加载，提供加载状态；无匹配证据时明确提示，不误标其他句子。
- [ ] 保持现有权限边界：不在提交前或完整模考进行中泄露原文、答案或解析；复习仍从既有 attempt 接口按需加载。
- [ ] 验收：对至少一组多题听力材料逐题检查定位准确性、切题更新、无证据状态及刷新/返回行为。

**完成证据：** 覆盖材料/题目、验收记录、PR/提交链接。

## 建议交付顺序

1. UX-01 与 PERF-01 先复现并记录基线，可由不同开发者并行领取。
2. API-01 梳理个性化调用后实施去重和失败处理；若确认与 PERF-01 重叠，合并修复并在两个任务下互相链接。
3. LISTEN-01 实现原文定位与高亮，沿用现有提交后按需加载的数据接口。
4. 完成后由非领取人按验收项走查；记录未解决问题和后续负责人。
