# 学习数据、个性化与本机服务

## 界面

左侧导航栏宽度统一读 `--rail` 令牌，响应式断点只改这个令牌（1250px/900px/600px 分别为 210px/70px/59px）。导航栏可收起，收起时整条栏滑出视野、主内容补满全宽，偏好存在 `localStorage` 的 `ielts-rail-hidden`；收起后通过正文上方独立导航行内的按钮展开。导航行随页面滚动，为按钮保留空间，避免遮挡标题和正文；考前准备与机考作答仍隐藏整个导航行。

600px 及以下的计划预览将任务标题、题量与训练重点分行呈现，日期、时间预算和确认操作可换行，避免长材料名称挤压或覆盖说明文字。

设置页保存目标时显示“保存中”，暂时禁用表单以防重复提交；成功后留在设置页，在按钮旁持续显示“目标已保存”，修改字段后可再次保存。失败信息也在按钮旁显示，并保留输入供重试。保存接口通过一次 bootstrap 准备当日计划，不重复构造规划输入，AI 生成仍在后台进行。

## 本机服务
Node 服务绑定 127.0.0.1，React 页面由 Vite 提供；开发时 `/api`、`/media` 和 `/plugin-assets` 代理至本机服务。SQLite、个人学习记录和解压后的题库位于 `.data/`。可在 `.env` 设置 `IELTS_DATA_DIR` 与 `IELTS_SERVER_PORT`。

AI 配置由本机服务读取 `IELTS_AI_BASE_URL`、`IELTS_AI_MODEL`、`IELTS_AI_API_KEY`。密钥不发送给浏览器。没有配置时，导师与 AI 规划会提示暂不可用；练习、判分和错题复习仍可使用。完整模考进行中拒绝导师请求；提交后上下文允许解释程序已判定的结果。

## 画像证据

SQLite 保存目标、草稿、已提交作答、逐题用时、提示记录、用户确认错因、复习队列、计划与导师对话；Neon 使用对应的云端字段。题目内容来自只读内容包；组合模考另外在 `mock_papers` 保存固定试卷快照，以便题库变化后仍能恢复和复盘。客观题由插件判分器计算。

画像按科目和能力标签保存独立答对数、首次结果、提示比例、确认错因和用时。近 30 天作为主要信号，历史记录作为基线。能力少于 3 道独立作答新题时显示“证据不足”，用于安排基线练习，不直接判为弱项。题目复习结果单独记录，不参与新题迁移表现。只有此前未独立作答的题目用于迁移评估。

练习页按当前可见题目计时；切换到后台或离开页面时暂停。逐题用时约每 5 秒自动保存，刷新或返回后恢复。题型/能力组合少于 5 个有效计时样本时，按材料预估总时长与题量折算；达到 5 个样本后用近期单题时长中位数估算。

活动的 `part` 分段字段用于列表分组、练习页标识和组合模考选材。模考时钟与逐题用时分别处理：逐题用时仅统计可见作答时间，模考截止时间在后台、刷新和故障期间持续推进。模考错题按原材料 ID 进入复习，题目 ID 继续用于独立新题去重。完整规则见 [computer-exam.md](computer-exam.md)。

## 每日计划与复习

每天按台北自然日生成一份当天计划，不再生成七日材料清单。候选任务由材料、题型和能力标签组成的小题组构成；同一 `groupId` 或 `answerGroupId` 关联的题目始终成组。计划任务保存实际 `questionIds`，服务端只向练习页呈现并评分这些题。

规划请求只向 AI 发送目标、考试日期、时间预算、近期/历史画像、到期错题及候选题组 ID、题型、能力标签、题量和估算时长；不发送题干、答案、解析、录音文本或导师对话。服务端重新校验候选 ID、题组范围、任务重复、关联题完整性和每日时间预算；任务时长由题库及有效计时样本确定。AI 失败或校验失败时不生成规则兜底计划，保留原有计划，并允许用户从题库自主练习或重试。

当天首次打开应用时生成当天方案，用户预览并确认后当天固定。当天完成练习、确认错因或修改目标不会重排已确认任务；这些信息用于下一自然日。次日 AI 会重新评估昨天未完成任务，不会全部自动顺延。确认新日方案时保留锁定/已完成任务，替换当天未锁定且未完成的任务，并将旧的未完成任务标为过期。升级时，缺少题目 ID 的旧版待办会在 SQLite 和 Neon 中标为过期，避免整份材料被误当成计划小题组。暂不应用则保留现状。方案日期、状态和题组 ID 同时保存在 SQLite 与 Neon。

错题复习按独立答对次数使用 1、3、7、14 天间隔，答错则次日再试。复习结果只更新复习队列，不混入新题迁移画像。完整模考结果不会被换算成未经验证的 Band 分数。

## 数据与性能

音频以文件流从 `.data/media/` 播放。本机内容导出保留完整题库，只读 SQLite 中的题库表，校验练习和音频引用后写入 `.data/content/activities.json`，再将清单及被引用音频归档到 `.data/ielts-content-v1.tar`；当前内容包约读取和归档 1.1 GB 音频。本机网页使用完整清单。云端上传脚本从该清单中过滤非高频及未标频听力活动，当前上传约 822 MB 音频。在本机 SSD 上导出预计约一分钟内完成，速度取决于磁盘吞吐；题目清单常驻内存，音频逐文件流式归档，峰值内存预期低于 512 MB。若处理超过 5 分钟或占用超过 1 GB 内存，再做定向性能分析。学习数据库不会进入归档。
